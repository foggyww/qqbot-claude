# Spec 0005: MCP

## Status
Accepted

## Scope

项目内 MCP Host、内置 QQ MCP server、插件 MCP server。主要涉及 `src/mcp/host.ts`、`src/mcp/qq-server.ts`、`src/plugin/index.ts` 和插件提供的 MCP server。

## Goals

- 让 Claude Code 通过统一 MCP Host 调用 QQ 和插件工具。
- 防止 MCP 工具绕过核心 adapter 或生命周期。

## Rules

- MCP Host 必须随 `Bot.start()` 启动，随 `Bot.stop()` 停止。
- 内置 QQ MCP server 必须复用当前 `QQAdapter`。
- 禁止 MCP server 自己创建新的 QQ/OneBot 连接。
- 禁止调用旧 Python HTTP API。
- 插件如需 MCP，应通过 `Plugin.mcpServers` 暴露。
- MCP 工具失败应返回结构化错误，不能泄漏密钥。

## Behavior

- 默认 endpoint 是 `http://127.0.0.1:8765/mcp/<server>`。
- Host 可通过 `QQBOT_MCP_HOST`、`QQBOT_MCP_PORT` 覆盖监听地址。
- 内置 `qqbot` MCP server 提供发消息、查群、查成员、查历史、撤回、用户映射等工具。

## Error Handling

- JSON-RPC 请求格式错误应返回协议错误。
- 工具参数无效应返回明确错误。
- Adapter 调用失败应转为工具错误响应。

## Security

- MCP 监听默认本机地址。
- 工具不得返回完整私有配置或密钥环境变量。
- QQ 操作权限应由上游对话权限和工具设计共同限制，不能提供任意越权入口。

## Tests

修改本范围时应考虑增加 MCP host/server 测试，并至少执行：

- `npm run typecheck`
- `npm test -- --run`

## Acceptance Checklist

- [ ] QQ MCP 仍复用 `QQAdapter`。
- [ ] MCP 生命周期仍由 Bot 管理。
- [ ] 工具错误是结构化的。
