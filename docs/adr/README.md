# Architecture Decision Records

`docs/adr/` 记录长期架构决策。ADR 用来解释“为什么这么设计”，防止未来重复争论或无意回退。

## ADR 模板

```markdown
# ADR-NNNN: 标题

## Status
Proposed | Accepted | Deprecated

## Context
当时面临的问题和约束。

## Decision
最终选择。

## Rationale
选择原因。

## Consequences
带来的约束、收益和代价。
```
